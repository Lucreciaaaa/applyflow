## What is ApplyFlow?

ApplyFlow is a web application designed to analyze CVs against job descriptions and simulate early-stage recruitment evaluation.

The goal is to help candidates better understand:
- how their profile aligns with a role,
- which technical or domain signals are missing,
- and what weaknesses may reduce interview conversion.

The platform combines structured scoring logic with LLM-powered analysis to generate contextual feedback and actionable recommendations.

---

## Features

- CV upload and job description analysis
- Weighted match scoring engine (0–100%)
- Skill gap and missing keyword detection
- Recruiter / ATS signal analysis
- Structured LLM-powered feedback generation
- Context-aware evaluation depending on company environment
